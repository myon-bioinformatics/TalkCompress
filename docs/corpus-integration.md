## 往復実験で利用できる範囲

- 同梱4,734件は入力・トークン数・バイト数・ハッシュの検証対象。意味保持の合格データではない。
- 多言語の一般文・記事連結: Tatoeba/FLORES-200（20言語）。読み上げ文: ja/en/vi/th。文字化けと orig の対: ja/vi。絵文字・記号・コード等の混在文: ja/en。
- Common Voice は自発発話の書き起こしではない。mixed は主に記号・コード混在であり、自然な多言語コードスイッチ全般を代表しない。
- FLORES の medium と long は元文を共有する。学習・評価分割では記事URL単位で隔離し、重なりを防ぐ。tier の基準は生成スクリプトにより異なる。
- 全量生成は fetch_corpus_major.py / fetch_corpus_lowres.py で固定SHA-256を検証して実行できるが、この統合で再取得したとは扱わない。集計は同梱分のみ。
- ftfy_exact は機械的復元であり、LLM の意味保持・往復成功とは数えない。

BCI Authorized Vocabulary of Blissymbolics (BCI-AV) 2026

Here is the current BCI-AV. There are now a total of 6551 symbols. Several graphics formats are provided as well as accompanying documentation.  You can browse it online in Google Sheets format and several graphics formats are provided below for download as well as accompanying documentation. 

Full symbol sets in various formats

The file names below are mostly self-explanatory. The number after h indicates the height of the symbols and w indicates their width. The suffix indicates the type of files the map contains (e.g. png, bmp, svg or wmf). 

  • Release notes BCI-AV 2026-09-12
  • bliss_svg.zip
  • bliss_svg_id.zip
  • bliss_h1000_transp_png.zip
  • bliss_h432_transp_wmf.zip
  • bliss_h1000_bmp.zip
  • bliss_h188_documentation_png.zip
  • bliss_h188_documentation_id_png.zip
  • ID to gloss map text file
  • BCI-AV_2026-09-12 (WinBliss format)

Documentation on the symbol sets

  • Excel readable open docs spreadsheet with ID's, glosses, and derivations but without symbols (more manageable)
  • Google Sheets spreadsheet with ID's, glosses, symbols, and derivations
  • PDF (landscape format - larger symbols and text when printed) with symbols: English, Swedish, Norwegian, Finnish, Hungarian, German, Dutch, Afrikaans, Russian, Icelandic, Lithuanian, Latvian, Polsish, French, Spanish, Portuguese, Italian, Danish, Esperanto
  • PDF (portrait format - fewer pages) with symbols: English, Swedish, Norwegian, Finnish, Hungarian, German, Afrikaans, Icelandic, Lithuanian, Latvian, Polish
  • PDF (portrait) with symbols: English, Finnish, Hungarian, Dutch, Russian, Icelandic, Lithuanian, Latvian, French, Spanish, Portuguese, Italian, Danish
  • PDF (portrait) with symbols: English, Swedish, Norwegian, German, Afrikaans, Polish, Esperanto

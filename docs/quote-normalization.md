# 引用符正規化の範囲と未検証事項

MorphoZip は原則として曲がり引用符を直線引用符に変換する。語中の
アポストロフィや明示的な保護スパンは別扱いで、従来どおり保持する。

## 限定的な二重引用符の例外

`All At El How One She That These To Well With Yes` のいずれかで始まる、
行頭の完結した `“…”` 対は曲がり引用符を残す。これは #110 が報告した
o200k の語彙に基づく有限のヒューリスティックであり、全文のトークン数が
必ず減る・増えないという保証ではない。他の文脈や tokenizer への一般化も
していない。

- 語の続きを ASCII だけでなく Unicode の語文字・結合文字でも判定する。
  `“Allāh”`、`“Wellé”`、`“Well᷄”`、`“Well's”` はリストの単語とはみなさない。
- 空白や括弧の後ろの引用符は例外にしない。対は改行をまたがない。
- 圧縮の途中で先頭語が消える・変わる場合があるため、変換後にも条件を
  確認する。例えば `strip=True` の `“Well, I know.”`、`spelled_nums=True`
  の `“One cat.”` は、元の先頭語だけを理由に曲がり引用符を残さない。
- 保護スパンはこの再確認の後に復元する。引用された大文字 `A` の保持や
  Romance 文脈の判定を変更するものではない。

## テストと明示的な tokenizer 検査

`tests/test_curly_opener_merge.py` の通常テストは文字列・偽 tokenizer のみを
使用する。このファイル内の 2 本の実 tokenizer 検査は、
`TALKCOMPRESS_RUN_TOKENIZER_CHECKS=1` を明示した場合だけ import／encoding
取得へ進む。tiktoken がインストール済みでも既定では skip する。

```sh
# 通常の文字列・偽データ検査（このファイルの実 tokenizer 検査は skip）
uv run pytest tests/test_curly_opener_merge.py

# 別途、実測を意図して明示実行する場合のみ。キャッシュがなければ辞書取得し得る。
TALKCOMPRESS_RUN_TOKENIZER_CHECKS=1 uv run pytest tests/test_curly_opener_merge.py
```

この opt-in は上記ファイルに限る。既存の他のテストや計測スクリプト全体が
ネットワーク・tokenizer 不使用になったという意味ではない。

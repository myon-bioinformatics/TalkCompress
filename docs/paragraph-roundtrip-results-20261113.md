## 言語ごとの目立った失敗と理由

**英語（損失が大きい。表記ゆれは許容できている）。** CEF の exact 平均は 69.6% まで落ちるが、notation_tolerant は 81.5% まで戻る。通った例: `eighteen` → `18`（`en-flores-05|CEF`）、`father’s` → `father's`（`en-flores-03`）。通らない例は語の意味が変わるもの: `at least` → `about`（`en-flores-02|CEF` seed 2、「少なくとも」が「およそ」になる）、`Out of … prior to` → `Of … before` と `per cent` が同時に変わる文（`en-flores-04|CEF`。`%` だけなら許容だが、前置詞の言い換えが残る）。`en-flores-03` は 3 方式とも肺の成熟（lung maturation）周辺を言い換え、seed 3 の control は 0/4 まで落ちた。BEF の段落 exact が 2.8% と極端に低いのは、文は戻っても `|` や引用のあとで行が分かれ、`en-pd-04` のように「And:」行が足されることがあるためである。

**ドイツ語。** CEF はほぼ control どおり。BEF の落ちは同義語が中心で、`Antwort` → `Reaktion`（`de-flores-01|BEF`）。圧縮トークンを「答え」ではなく「反応」で戻している。

**スペイン語。** 3 シードとも CEF/BEF の exact が 82.4% で幅が 0。再現性の高い失敗は `es-flores-04` の「Desde 2008」（圧縮では `←2008`）を `En comparación con 2008` や `Comparado con 2008` と戻すこと。起点の「以来」が「と比較して」に変わり、意味がずれる。

**フランス語。** CEF の exact は control と同じ 90.2%。共通の失敗は原文の `PEC` を `CEP` に直してしまうこと（`fr-flores-01`、control でも起きる）。判定役が頭字語の「誤り」を校正している。U+2019 のアポストロフィだけの差は notation_tolerant で通る。

**ポルトガル語。** シード差が最大。`pt-flores-01|CEF` は seed 1 で 5/5、seed 3 で 0/5（`prometeu` → `empossou` など）。同じ圧縮文でも判定役次第で完全一致にも全滅にもなる。control でも性の一致を直される例がある: `Eles são mais frios` → `Elas são mais frias`（`pt-flores-02`）。無圧縮に見える段落でも `se educou como` → `se formou como` のような言い換えが起きる。

**日本語（損失が最大）。** 原文側の表記ゆれや重複を判定役が直す。`ja-flores-01` の gold は「臨時選挙管理委員会会（CEP）」（「会」が重なっている）で、判定は「委員会（CEP）」に直し、さらに「マルテリー氏」と「氏」を足すことがある。助詞の取り違え（は → が）も残る。CEF/BEF ではこれが圧縮の置換と重なり、exact 平均は 60.8% / 52.9% まで落ちる。表記表では助詞も接尾も救えない。

**中国語。** exact の損失は小さいが、シード 3 の `zh-flores-01|control` は 0/5 で、`马特利` 周辺だけでなく「在…中宣誓就职」が「为…主持了宣誓就职仪式」に変わり、宣誓した主体がずれる。一方、`从 1959 年` ↔ `从1959年` や `（Liggins）` ↔ ` (Liggins) ` は表記として一致する（`zh-flores-03|BEF` 第 2 文はこの修正の対象だった）。そのため notation_tolerant では CEF/BEF が control を上回る。

**イタリア語。** 3 シード・3 方式とも文も段落も 100%。このセットでは圧縮も判定ノイズも観測されなかった。

**オランダ語。** 文の exact は control 100%、CEF 96.1%。段落 exact だけ 25% なのは、上述のとおり merge_split である。BEF は `zwoor` → `beëdigde`、英語の組織名をフランス語名に置き換えるなど、同義語ドリフトが出る（`nl-flores-01|BEF`）。

**ギリシャ語。** control の exact が 72.5% と低く、CEF 82.4% のほうが高い（損失が負）。判定ノイズが圧縮損失より大きい。`Ελισάβετ Β΄να` と `Β΄ να` の空白差は notation_tolerant で通る（`el-flores-04`）。ギリシャ語 CEF は 4 段落とも無圧縮なので、差は判定役のぶれそのものである。

**チェコ語。** 損失が大きい。`přísahal` → `složil přísahu`、`Je to` → `Jedná se o`、接続の `a` を `z nichž` で補う、といった言い換えが CEF/BEF で繰り返される。BEF では「Alžběta II.」のあとで行が分かれ、接続詞 `a` が落ちる（`cs-flores-04|BEF`、「34 procent … sdílí tento názor a chtějí」→「… názor chtějí」）。

**ポーランド語。** control が最も弱い（exact 平均 60.8%）。`przysięgał w dniu wczorajszym` → `zaprzysiągł wczoraj`、`jego taty` → `swojego ojca` のように、無圧縮でも文体を整える。BEF の exact は 78.4% で control より高い。圧縮が「助けた」というより、判定役が無圧縮の散文をより自由に書き換える、と見るべきである。

**ラテン語。** control と BEF は平均 97.6%。CEF の主な失敗は `XV` → `quindecim`（`la-caesar-04`）。ローマ数字と語形の数詞は表記表の外（語彙の置き換え）なので、notation_tolerant でも落とす。seed 3 の control でも同じ置き換えが起き、`nonnumquam` や `a proelio` の書き換えもあった。

## 読み方

1. 厳密な exact と、表記を許した notation_tolerant は意図的に分けてある。後者で上がる分は「誤りが減った」のではなく、「新聞表記として同じ」と数えた分である（t1208u）。
2. control との差だけを圧縮品質とみなすと、ポーランド語・ギリシャ語のように判定ノイズが大きい言語では符号が逆に出る。必ず control の失敗件数を並記する。
3. 英語はよく縮むが、同義語への戻りも多い。日本語・チェコ語はあまり縮まないのに文一致の損失が大きい。イタリア語はこのセットでは両方とも問題にならなかった。
4. トークンを直接英語経由で往復させたときの失敗は、このベンチの範囲では多い。しかし t1204u のとおり、英語に戻さない使い方（短い形のまま読む、別言語のまま展開する、など）まで「意味がない」とは言えない。その可否はこの 3 シードでは測っていない。
5. 再現: `uv run python scripts/paragraph_roundtrip.py ingest --seed N`（N=1,2,3）、`score`、`uv run python scripts/paragraph_replay.py --check`。raw / blind / results は `SentenceCalibratedMosaic/fixtures/paragraph_judge/` にある。
